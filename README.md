# PPLTrades

Клиентский Fabric-мод для торговой зоны [PepeLand](https://www.pepeland.net/wiki/worlds/trading). Показывает категории и цены в подсказках к предметам и помогает найти нужный товар по табличкам.

[Сайт со статистикой цен — ppltrades.pages.dev](https://ppltrades.pages.dev).

## Как пользоваться

- **Shift над предметом** — показывает торговую категорию. На PepeLand при наличии данных также видны медианная, минимальная и средняя цены, число лотов и изменение цены относительно предыдущего периода. Цены указаны в алмазах за штуку или стак.
- **I над предметом** — открывает окно с историей цен и предложениями.
- **N над предметом** в инвентаре или списке JEI — подсвечивает подходящие таблички через Pochatok. Поиск учитывает переносы строк и распространённые торговые названия: например, «Редстоун блок» и «Блок редстоуна». Чтобы убрать подсветку, введите `/signsearch` без аргументов.

## Установка

1. Установите **Minecraft Java Edition 26.3**, **Java 25** и [Fabric Loader](https://fabricmc.net/use/installer/) версии **0.20.1** или новее.
2. Скачайте JAR из [актуального релиза](https://github.com/SinkQ/PPLTrades/releases/latest) и положите его в папку `mods` вместе с [Fabric API](https://modrinth.com/mod/fabric-api) для Minecraft 26.3.
3. Для поиска по табличкам установите [Pochatok](https://modrinth.com/mod/pochatok) для Minecraft 26.3. [JEI](https://modrinth.com/mod/jei) необязателен.

## Настройки и данные

С [Mod Menu](https://modrinth.com/mod/modmenu) и [Cloth Config](https://modrinth.com/mod/cloth-config) откройте **Моды → PPLTrades → Настройки**. Свои названия вводятся по одному на строку: `minecraft:redstone_block = ред блок`. Для нескольких названий одного предмета повторите его ID.

Обе библиотеки необязательны. Без них можно редактировать `config/ppltrades.json`, который создаётся при первом запуске. Изменения из меню применяются после сохранения, кроме адреса сервиса: для него (как и для правок JSON вручную) нужен перезапуск игры.

| Поле | Назначение |
| --- | --- |
| `collectPrices` | Отправлять наблюдения из открытых торговых бочек на PepeLand. По умолчанию включено. Установите `false`, если хотите только смотреть цены. |
| `showPrices` | Показывать цены в подсказках. По умолчанию включено; отключение не выключает отправку наблюдений. |
| `apiUrl` | HTTPS-адрес сервиса цен (по умолчанию `https://ppltrades.pages.dev`). Пустая строка отключает и загрузку цен, и отправку наблюдений. Поиск по табличкам от него не зависит. |
| `mirrorUrls` | Запасные HTTPS-адреса сервиса цен. Добавляйте только доверенные зеркала PPLTrades. По умолчанию пусто. |
| `proxy` | `system` (по умолчанию) — системный прокси Windows или `HTTPS_PROXY`/`HTTP_PROXY`; `none` — напрямую; или `http://127.0.0.1:10809`. Нужен HTTP-прокси: SOCKS встроенный клиент Java не поддерживает. Если через прокси не вышло, мод пробует напрямую. |
| `notifyUpdates` | Сообщать в чате о новой версии мода. Ссылки принимаются только на релизы официального репозитория PPLTrades на GitHub. По умолчанию включено; сообщение приходит один раз за запуск игры. |
| `signSearchAliases` | Дополнительные названия для поиска. Например: `{"minecraft:redstone_block": ["ред блок"]}`. До 200 названий всего, до 32 на предмет и до 128 символов на название. Для пользовательской части поисковой маски также действует лимит длины. |

При включённом сборе мод отправляет сервису цен сведения о товарах в открытых торговых бочках, координаты, текст табличек, адрес игрового сервера и хэш сида мира (не сам сид). Для отправки сервис подтверждает Minecraft-аккаунт через Mojang. Указывайте только доверенные адреса сервиса и зеркал: они могут получать эти наблюдения. Чтобы не отправлять данные, отключите `collectPrices`.

## Сборка из исходников

Нужен JDK 25 или новее. Из корня репозитория выполните:

```sh
./gradlew build
```

В Windows PowerShell: `.\gradlew.bat build`. Сборка запускает проверки клиента, включая поисковые маски, настройки, сетевой транспорт и уведомления об обновлениях. Готовый мод — `build/libs/ppltrades-1.0.3+26.3.jar`.
