# PPLTrades

Клиентский Fabric-мод для торговой зоны [PepeLand](https://www.pepeland.net/wiki/worlds/trading). Показывает категории и цены в подсказках к предметам и помогает найти нужный товар по табличкам.

## Как пользоваться

- **Shift над предметом** — показывает торговую категорию. На PepeLand при наличии данных также видны медианная, минимальная и средняя цены, число лотов и изменение цены относительно предыдущего периода. Цены указаны в алмазах за штуку или стак.
- **N над предметом** в инвентаре или списке JEI — подсвечивает подходящие таблички через Pochatok. Поиск учитывает переносы строк и распространённые торговые названия: например, «Редстоун блок» и «Блок редстоуна». Чтобы убрать подсветку, введите `/signsearch` без аргументов.

## Установка

1. Установите **Minecraft Java Edition 26.3**, **Java 25** и [Fabric Loader](https://fabricmc.net/use/installer/) версии **0.20.1** или новее.
2. Положите в папку `mods` файл `ppltrades-1.jar` (см. сборку ниже) и [Fabric API](https://modrinth.com/mod/fabric-api) для вашей версии Minecraft.
3. Для поиска по табличкам установите [Pochatok](https://modrinth.com/mod/pochatok) для Minecraft 26.3. [JEI](https://modrinth.com/mod/jei) необязателен.

## Настройки и данные

Файл `config/ppltrades.json` создаётся при первом запуске. Изменения применяются после перезапуска клиента.

| Поле | Назначение |
| --- | --- |
| `collectPrices` | Отправлять наблюдения из открытых торговых бочек на PepeLand. По умолчанию включено. Установите `false`, если хотите только смотреть цены. |
| `showPrices` | Показывать цены в подсказках. По умолчанию включено; отключение не выключает отправку наблюдений. |
| `apiUrl` | Адрес сервиса цен. Пустая строка отключает и загрузку цен, и отправку наблюдений. Поиск по табличкам от него не зависит. |
| `signSearchAliases` | Дополнительные названия для поиска. Например: `{"minecraft:redstone_block": ["ред блок"]}`. |

При включённом сборе мод отправляет сервису цен сведения о товарах в открытых торговых бочках, координаты и исходный текст табличек. Для отправки сервис подтверждает Minecraft-аккаунт через Mojang.

## Сборка из исходников

Нужен JDK 25 или новее. Из корня репозитория выполните:

```sh
./gradlew build
```

В Windows PowerShell: `.\gradlew.bat build`. Сборка запускает тесты поисковых масок; готовый мод будет в `build/libs/ppltrades-1.jar`.
